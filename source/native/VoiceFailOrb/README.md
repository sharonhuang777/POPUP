# 匹配失败 · 中间球体动画（Lottie）

- 文件：`voice_fail_orb.json`，Lottie 格式，透明背景，约 42 KB（内嵌了一张 240px 的灰化球体 PNG，其余是矢量）。
- 画布 240×240，30fps，27 秒一个无缝循环，直接 `loop` 播放即可，没有入场段。中心对准设计稿里球心（画板 x=201, y=357）。
- 内容：
  - 虚线轨道（直径约 190，1.5px，rgba(130,112,180,.40)）带两颗小圆点，匀速顺时针转一圈 27 秒。
  - 中间球体（120px，已经按设计稿做了 60% 去色和 1.04 提亮，透明度 82%）每 4.5 秒上下浮动 5px，投影跟随。
- 系统「减弱动态效果」开启时停在第 0 帧。
- 与设计稿的差别：网页版轨道转一圈是 26 秒，这里改成 27 秒（正好 6 次浮动），这样整段可以无缝循环，速度差不到 4%，看不出来。
- iOS 用 lottie-ios，Android 用 lottie-android，都能直接读取内嵌图片。`preview.html` 联网后可在浏览器预览。
